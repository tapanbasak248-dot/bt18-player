# BT18 dealer media assets

Place the six supplied MP4 clips in this folder using these filenames:

| Game | MP4 file |
| --- | --- |
| Head & Tail | 91246.mp4 |
| Dragon vs Tiger | 91245.mp4 |
| Big & Small | 91248.mp4 |
| Teen Patti | 91244.mp4 |
| Lucky Dice | 91247.mp4 |
| Roulette | 91243.mp4 |

The player page loads the matching clip for each game and falls back to its animated demo host when a file is unavailable. The MP4 binaries are not currently present in this repository, so the video requirement is not complete until these six files are added.

Use browser-compatible MP4 (H.264 video, AAC audio) where possible.
